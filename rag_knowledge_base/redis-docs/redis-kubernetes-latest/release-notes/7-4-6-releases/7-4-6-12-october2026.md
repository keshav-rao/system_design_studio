## Highlights

This is a maintenance release to support [Redis Software version 7.4.6-293](https://redis.io/docs/latest/operate/rs/release-notes/rs-7-4-2-releases). For version changes, supported distributions, and known limitations, see the [release notes for 7.4.6](https://redis.io/docs/latest/operate/kubernetes/release-notes/7-4-6-releases).

## Enhancements

- The operator now defers automatic REAADB repairs while a participating cluster is unhealthy or unreachable <!--RED-218555-->

## Resolved issues

- Fixed REAADB creation failing with a 406 error when `tlsMode` is `enabled` and the spec doesn't set `clientAuthenticationCertificates` <!--RED-217047-->
