**This release has been recalled.** Don't install Redis Software for Kubernetes version 8.0.20-21 or upgrade to it. Use [Redis Software for Kubernetes version 8.0.20-25](https://redis.io/docs/latest/operate/kubernetes/release-notes/8-0-20-releases/8-0-20-25-july2026) or later instead. Version 8.0.20-25 includes [Redis Software version 8.0.20-68](https://redis.io/docs/latest/operate/rs/release-notes/rs-8-0-releases/rs-8-0-20-68), which fixes an internal certificate issue that can cause upgrades to fail (RS199373).


## Highlights

This is a maintenance release to support Redis Enterprise Software version 8.0.20-19. For version changes, supported distributions, and known limitations, see the [release notes for 8.0.18-11 (April 2026)](https://redis.io/docs/latest/operate/kubernetes/release-notes/8-0-18-releases/8-0-18-11-april2026).
