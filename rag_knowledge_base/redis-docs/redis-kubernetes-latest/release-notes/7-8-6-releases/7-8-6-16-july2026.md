Redis Enterprise for Kubernetes 7.8.6-16 (July 2026) is a maintenance release that includes support for [Redis Software 7.8.6-286](https://redis.io/docs/latest/operate/rs/release-notes/rs-7-8-releases).

For supported distributions, known limitations, and API changes, see [Redis Enterprise for Kubernetes 7.8.6-1 March 2025 release notes](https://redis.io/docs/latest/operate/kubernetes/release-notes/7-8-6-releases/7-8-6-1-march2025).
