## Supported distributions

Redis Software for Kubernetes is compatible with [CNCF-conformant](https://www.cncf.io/training/certification/software-conformance/) Kubernetes platforms. The operator follows standard Kubernetes APIs and practices and is designed to run consistently across certified Kubernetes environments.

The following table shows supported Kubernetes versions at the time of this release. For a list of platforms tested with this release, see [Supported Kubernetes distributions](https://redis.io/docs/latest/operate/kubernetes/reference/supported_k8s_distributions).

| Kubernetes | **Redis <nobr>8.2.0</nobr>** |
|---|---|
| 1.36 | Supported |
| 1.35 | Supported |
| 1.34 | Supported |
| 1.33 | Supported |
| 1.32 | Deprecated |
