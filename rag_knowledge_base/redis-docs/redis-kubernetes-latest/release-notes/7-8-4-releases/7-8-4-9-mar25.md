This is a maintenance release to support [Redis Enterprise Software version 7.8.4-95](https://redis.io/docs/latest/operate/rs/release-notes/rs-7-8-releases/rs-7-8-4-95) and OpenShift 4.17 and 4.18.

For version changes and known limitations, see the [release notes for 7.8.2-6 (Nov 2024)](https://redis.io/docs/latest/operate/kubernetes/release-notes/7-8-2-releases/7-8-2-6-nov24).
