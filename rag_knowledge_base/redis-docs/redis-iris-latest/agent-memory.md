Redis Agent Memory provides persistent session memory and long-term memory for AI agents and applications.

![The Agent Memory page in the Redis Cloud console, with Quick create and Create custom service options.](https://redis.io/docs/latest/images/rc/agent-memory-get-started.png)

## Deployment options

### Redis Cloud

Use Redis Agent Memory as a managed service on Redis Cloud.

[Create a Redis Agent Memory service](https://redis.io/docs/latest/operate/iris/agent-memory/create-service), [configure its AI models](https://redis.io/docs/latest/operate/iris/agent-memory/model-configuration), or [view and manage an existing service](https://redis.io/docs/latest/operate/iris/agent-memory/view-service).

### Self-managed

Deploy, configure, secure, and operate Redis Agent Memory on your own Kubernetes infrastructure.

[Open the self-managed Redis Agent Memory documentation](https://redis.io/docs/latest/operate/iris/agent-memory/self-managed)
