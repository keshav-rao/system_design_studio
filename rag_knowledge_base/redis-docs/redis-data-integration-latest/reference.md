For API clients, [RDI API v1 is deprecated as of RDI 1.19.0](https://redis.io/docs/latest/integrate/redis-data-integration/reference/api-migration).
Use [RDI API v2](https://redis.io/docs/latest/integrate/redis-data-integration/reference/api-reference) for new integrations and migrate existing clients. API v1 will not be extended with new RDI features and may be removed in a future RDI version.
