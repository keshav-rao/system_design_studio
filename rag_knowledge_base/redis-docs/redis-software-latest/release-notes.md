Configurable minimum password length. Configurable license expiration alert threshold. | Redis 7.4, 7.2, 6.2 |

Sharded pub/sub. Preview of the new Cluster Manager UI. Redis Stack 7.2 features. Three Redis database versions. License file structure updates.
