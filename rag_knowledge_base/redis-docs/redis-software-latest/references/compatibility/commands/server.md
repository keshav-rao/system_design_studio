The following tables show which Redis Open Source [server management commands](/content/commands?group=server) are compatible with standard and Active-Active databases in Redis Software and Redis Cloud.

## Access control commands

Several access control list (ACL) commands are not available in Redis Software. Instead, you can manage access controls from the [Redis Software Cluster Manager UI](https://redis.io/docs/latest/operate/rs/security/access-control) and the [Redis Cloud console](https://redis.io/docs/latest/operate/rc/security/access-control/data-access-control/role-based-access-control).

Redis Cloud manages modules for you and lets you [enable modules](https://redis.io/docs/latest/operate/rc/databases/create-database#modules) when you create a database.
