`rladmin node` commands manage nodes in the cluster.


| Command | Description |
| --- | --- |
| [addr](https://redis.io/docs/latest/operate/rs/references/cli-utilities/rladmin/node/addr/) | Sets a node's internal IP address. |
| [enslave](https://redis.io/docs/latest/operate/rs/references/cli-utilities/rladmin/node/enslave/) | Changes a node's resources to replicas. |
| [external_addr](https://redis.io/docs/latest/operate/rs/references/cli-utilities/rladmin/node/external-addr/) | Configures a node's external IP addresses. |
| [maintenance_mode](https://redis.io/docs/latest/operate/rs/references/cli-utilities/rladmin/node/maintenance-mode/) | Turns quorum-only mode on or off for a node. |
| [recovery_path](https://redis.io/docs/latest/operate/rs/references/cli-utilities/rladmin/node/recovery-path/) | Sets a node's local recovery path. |
| [remove](https://redis.io/docs/latest/operate/rs/references/cli-utilities/rladmin/node/remove/) | Removes a node from the cluster. |
| [snapshot](https://redis.io/docs/latest/operate/rs/references/cli-utilities/rladmin/node/snapshot/) | Manages snapshots of the configuration of a node's shards and endpoints. |
