The `crdb-cli task` commands help investigate Active-Active database performance issues.  They should not be used except as directed by Support.

## `crdb-cli task` commands


| Command | Description |
| --- | --- |
| [cancel](https://redis.io/docs/latest/operate/rs/references/cli-utilities/crdb-cli/task/cancel/) | Attempts to cancel a specified Active-Active database task. |
| [list](https://redis.io/docs/latest/operate/rs/references/cli-utilities/crdb-cli/task/list/) | Lists active and recent Active-Active database tasks. |
| [status](https://redis.io/docs/latest/operate/rs/references/cli-utilities/crdb-cli/task/status/) | Shows the status of a specified Active-Active database task. |
