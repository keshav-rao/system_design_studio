## New features

### Active-Active on Redis Cloud BYOC

You can now deploy [Active-Active databases](https://redis.io/docs/latest/operate/rc/databases/active-active/create-active-active-database) to [Redis Cloud Bring your own Cloud](https://redis.io/docs/latest/operate/rc/subscriptions/bring-your-own-cloud).
