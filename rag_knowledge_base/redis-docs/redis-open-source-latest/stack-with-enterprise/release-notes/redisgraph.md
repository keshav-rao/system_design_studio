Redis, Inc. has announced the end of life for RedisGraph. We will carry out the process gradually and in accordance with our commitment to our customers. See [details](https://redis.com/blog/redisgraph-eol/).



| Version (Release date) | Major changes | Min Redis version | Min cluster version |
| --- | --- | --- | --- |
| [v2.10 (November 2022)](https://redis.io/docs/latest/operate/oss_and_stack/stack-with-enterprise/release-notes/redisgraph/redisgraph-2.10-release-notes/) | Introduces new path algorithms, additional expressivity (constructs and functions), performance improvements, and bug fixes. | 6.2.0 | 6.2.8 |
| [v2.8 (February 2022)](https://redis.io/docs/latest/operate/oss_and_stack/stack-with-enterprise/release-notes/redisgraph/redisgraph-2.8-release-notes/) | Introduces multi-labeled nodes, indexes over relationship properties, and additional expressivity (Cypher construct, functions, and operators). Major performance enhancements. Many bug fixes. | 6.2.0 | 6.2.8 |
| [v2.4 (March 2021)](https://redis.io/docs/latest/operate/oss_and_stack/stack-with-enterprise/release-notes/redisgraph/redisgraph-2.4-release-notes/) | Added Map and Geospatial Point data types. | 6.0.0 | 6.0.8 |
| [v2.2 (November 2020)](https://redis.io/docs/latest/operate/oss_and_stack/stack-with-enterprise/release-notes/redisgraph/redisgraph-2.2-release-notes/) | Support for scaling reads, OPTIONAL MATCH, query caching, and GRAPH.SLOWLOG. | 5.0.7 | 6.0.8 |
| [v2.0 (January 2020)](https://redis.io/docs/latest/operate/oss_and_stack/stack-with-enterprise/release-notes/redisgraph/redisgraph-2.0-release-notes/) | Enabled graph-aided search and graph visualisation. Cypher coverage. Performance improvements. | 5.0.7 | 5.4.11 |
| [v1.2 (April 2019)](https://redis.io/docs/latest/operate/oss_and_stack/stack-with-enterprise/release-notes/redisgraph/redisgraph-1.2-release-notes/) | Support multiple relationships of the same type R connecting two nodes. Lexer elides escape characters in string creation. Performance improvements. | 4.0.0 | 5.0.0 |
| [v1.0 (November 2018)](https://redis.io/docs/latest/operate/oss_and_stack/stack-with-enterprise/release-notes/redisgraph/redisgraph-1.0-release-notes/) | Fixed memory leaks. Support ‘*’ within RETURN clause. Added TYPE function. Initial support for UNWIND clause. | 4.0.0 | 5.0.0 |
