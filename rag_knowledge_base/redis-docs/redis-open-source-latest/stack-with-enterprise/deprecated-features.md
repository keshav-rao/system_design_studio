The following features (modules) have been deprecated or replaced with a new version:


| Feature | Description |
| --- | --- |
| [Triggers and functions](https://redis.io/docs/latest/operate/oss_and_stack/stack-with-enterprise/deprecated-features/triggers-and-functions/) | Trigger and execute JavaScript functions in the Redis process |
| [Graph](https://redis.io/docs/latest/operate/oss_and_stack/stack-with-enterprise/deprecated-features/graph/) | RedisGraph is a queryable graph database built on Redis. |
| [Gears](https://redis.io/docs/latest/operate/oss_and_stack/stack-with-enterprise/deprecated-features/gears-v1/) | RedisGears supports batch and event-driven processing for Redis data. |
